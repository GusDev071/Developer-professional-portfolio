Bienvenido al repositorio de mi portafolio profesional. Este proyecto ha sido diseñado para presentar mi experiencia, habilidades y proyectos destacados como **Desarrollador Full Stack**, utilizando un stack tecnológico moderno y eficiente.

## 🚀 Características Principales

-   **Diseño UI/UX Moderno**: Interfaz limpia y minimalista enfocada en la experiencia de usuario.
-   **Totalmente Responsivo**: Adaptable a dispositivos móviles, tablets y escritorio.
-   **Soporte Multi-idioma (i18n)**: Contenido disponible en **Español** e **Inglés**, gestionado a través de Context API.
-   **Animaciones Interactivas**:
    -   Efectos de escritura ("Typing Effect").
    -   Aparición de elementos al hacer scroll (`ScrollReveal`).
-   **Arquitectura Escalable**: Estructura de componentes modular y tipado estático estricto.

## 🛠️ Stack Tecnológico

El proyecto está construido sobre las siguientes tecnologías:

-   **Core**: [React 19](https://react.dev/)
-   **Lenguaje**: [TypeScript](https://www.typescriptlang.org/)
-   **Estilos**: [Tailwind CSS v4](https://tailwindcss.com/)
-   **Empaquetador**: [Vite](https://vitejs.dev/)
-   **Calidad de Código**: ESLint + TypeScript-ESLint

## 📂 Estructura del Proyecto

```bash
src/
├── components/   # Componentes de UI (Navbar, Hero, Footer, etc.)
├── context/      # Gestión de estado global (LanguageContext)
├── data/         # Textos, traducciones y datos estáticos
├── db/           # Base de datos simulada o datos de proyectos
├── pages/        # Secciones principales de la página
├── types/        # Definiciones de tipos e interfaces TypeScript
├── App.tsx       # Componente raíz y orquestación de secciones
└── main.tsx      # Punto de entrada de la aplicación
```

## 🔧 Instalación y Despliegue

Sigue estos pasos para ejecutar el proyecto en tu entorno local:

1.  **Clonar el repositorio**
    ```bash
    git clone https://github.com/GusDev071/Developer-professional-portfolio.git
    cd portafolio
    ```

2.  **Instalar dependencias**
    ```bash
    pnpm install
    ```

3.  **Iniciar servidor de desarrollo**
    ```bash
    pnpm dev
    ```

4.  **Construir para producción**
    ```bash
    pnpm build
    ```
